## Important

- Confirm license and redistribution conditions for **each set of weights**, not just code. Hunyuan3D uses a Tencent community license; SAM 3D Objects is gated.
- On Hugging Face free accounts, public storage is best-effort; large-scale duplicate storage can be restricted. See https://huggingface.co/docs/hub/storage-limits.
- For true independent backups, store the permitted checkpoint files in repositories/storage you control, preserve notices, record exact model revisions/hashes, and verify integrity after upload.
